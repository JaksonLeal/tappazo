Prueba de voz

Conecta este navegador a una sala LiveKit. Abre otra pestaña para conectar al segundo jugador.

En Postman, usa el JWT del jugador y envía POST /api/v1/games/{{gameId}}/voice-token. Pega aquí el campo token de la respuesta, no el JWT de Tappazo.

Desconectado

La página no guarda los tokens. Al cerrar o recargarla, vuelve a pegarlos.

    Usa audífonos para evitar eco. El navegador solicitará permiso para usar el micrófono. Esta herramienta sirve para pruebas locales, no para producción.
